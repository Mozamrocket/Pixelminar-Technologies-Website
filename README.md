# Pixelminar Technologies Website

Official website of Pixelminar Technologies: company info, apps, privacy policies, terms and data-deletion page (used for the Google Play Console organization account).

## Pages
- `index.html` – Home, apps, about, contact
- `privacy-policy.html` – Company privacy policy
- `privacy/azan.html`, `privacy/med-reminder.html`, `privacy/expense-tracker.html` – App privacy policies
- `terms.html` – Terms of Service
- `data-deletion.html` – Data deletion instructions

## Hosting
Plain static HTML/CSS. Enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
